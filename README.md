# 소비자 피해구제 데이터 분석

한국소비자원의 **소비자 피해구제 데이터**를 활용하여 소비자 피해의 주요 유형과 발생 패턴을 분석하고 시각화한 프로젝트입니다.

## 프로젝트 목표

2023~2024년 소비자 피해구제 데이터를 바탕으로 피해가 많이 발생하는 **연령대, 지역, 판매유형, 시기 및 품목**을 파악하고 주요 패턴을 도출하는 것을 목표로 했습니다.

## 분석 과정

### 1. 데이터 전처리
- 분기별 CSV 데이터 통합
- 약 **10.5만 건**의 소비자 피해구제 데이터 분석
- 결측치 및 데이터 타입 확인
- 접수일을 날짜형으로 변환하고 월 변수 생성

### 2. 데이터 분석 및 시각화
- 성별·연령대별 피해 접수 현황
- 지역별 피해 발생 건수
- 판매유형별 피해 발생 현황
- 월별 피해 발생 추이
- 품목 및 청구이유별 피해 유형 분석
- 의류·운동 관련 품목의 월별 피해 추이 분석

## 주요 인사이트

- 피해 접수는 **30~39세**에서 가장 많이 발생
- 지역별로는 **경기도, 서울, 인천** 순으로 피해 접수가 많음
- 판매유형은 **일반판매와 국내 온라인 거래**의 비중이 높음
- 특정 시기와 품목에 따라 피해 발생 건수가 달라지는 패턴 확인

## 사용 기술

`Python` `Pandas` `NumPy`  
`Matplotlib` `Seaborn`
